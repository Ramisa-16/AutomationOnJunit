- Selenium WebDriver integration
- Page Object Model (POM)
- Data-driven testing
- Assertions and reporting

## 🚀 Getting Started

```bash
git clone https://github.com/Ramisa-16/AutomationOnJunit.git
cd AutomationOnJunit
mvn clean test
```
